# 约束松动核查清单

> **何时读取此文件**：在**阶段 1（约束松动验证）**开始时加载。当你需要系统地枚举"旧格局靠什么约束维持"、并逐条判定证据强度时读取本文。阶段 3（机制验证）中检查金融承诺结构时，也可回看文末的判别问题。

---

## 1. 六类约束清单

约束是维持旧格局的"护栏"。护栏没松动，趋势就没有底座。逐类排查，不要跳过任何一类。

### 成本约束
- 关键问题：核心投入品的单位成本是否下降？下降来自规模、技术还是补贴？
- 松动信号示例：单位成本同比下降、替代材料/替代工艺出现、关键原料价格回落。
- 注意：一次性补贴造成的降价是**可逆**的，不是结构性松动。

### 监管约束
- 关键问题：准入、牌照、标准、审批是否放宽？放宽是立法层面的还是试点层面的？
- 松动信号示例：新国标落地、准入门槛下调、试点城市扩容、审批时限缩短。
- 注意：试点放开 ≠ 全国放开，通常可逆。

### 技术约束
- 关键问题：曾经的"做不到"是否变成了"做得到"？是实验室可行还是量产可行？
- 松动信号示例：良率提升、性能达标、可规模化量产、关键专利到期。
- 注意：Demo 可用 ≠ 可量产，必须区分。

### 渠道约束
- 关键问题：触达用户的分发路径是否变宽？新渠道成本是否下降？
- 松动信号示例：新增销售渠道、平台流量成本下降、物流覆盖扩大。
- 注意：平台一次性扶持流量是**可逆**的。

### 习惯约束
- 关键问题：用户行为是否发生真实迁移？是否形成复购或留存？
- 松动信号示例：使用频次上升、复购率提升、留存曲线变平。
- 注意：尝鲜量与话题量不等于习惯迁移。

### 基础设施约束
- 关键问题：配套的算力、能源、物流、支付、网络等底座是否就绪？
- 松动信号示例：基础设施覆盖率提升、单位服务成本下降、标准接口统一。
- 注意：基础设施通常是**结构性**的，一旦建成不易回退。

## 2. 证据分层判定标准

对每条约束，只能标注为以下三级之一。**禁止**把"叙事"当成"硬证据"。

### 硬证据（Hard）
满足以下全部条件：
- 有**可公开查证**的来源（官方统计、上市公司财报/公告、海关数据、监管文件、可复现的一手观测）。
- 与约束直接相关，不需要额外推断链条。
- 已被**多次独立来源**交叉印证。

### 弱证据（Weak）
满足任一条件：
- 来源单一，或来自非权威二手转述。
- 与约束相关但需较长推断链条。
- 数据存在但样本、口径存疑，尚未被交叉验证。

### 叙事（Narrative）
- 只有观点、口号、情绪、KOL 转述，无法指向具体可查证的数据或文件。
- 或反复出现但每次都无法落到一手来源（"据说""业内认为""很快就要"）。

> 判定口诀：**能不能指出在哪份文件、哪个数据集、哪次统计里看到它？** 指不出来就是叙事。

## 3. 结构性 vs 可逆性 判别问题

对每条已松动的约束，回答下列问题，只要有一项指向"可逆"，就按可逆处理：

1. 如果补贴取消 / 政策转向 / 资本冷却，这项松动**会不会回退**？
2. 松动来自**底层要素**（技术曲线、基础设施、人口结构），还是来自**上层意志**（政策、资本、平台扶持）？
3. 同样的松动，在最近 5—10 年内是否**反复出现过又消失**？
4. 是否有**替代路径**也能维持旧格局（即松动并非唯一出路）？
5. 松动的**受益方**是分散的多数，还是少数集中主体（后者更易被逆转）？

判定结论只允许二选一：**结构性（不可回退倾向）** / **可逆（可能回退）**。
