# 证伪信号与退出规则模板

> **何时读取此文件**：在**阶段 4（证伪与退出）**开始时加载；阶段 5 撰写备忘录、阶段 6 定期复核时也需回看本文（复用退出条件写法并检查是否被触发）。

---

## 1. 证伪信号格式模板

每条证伪信号必须**可公开查证**，且能被第三者独立复核。禁止写成"感觉不对""气氛变了"这类主观表述。

```
信号 #N
- 陈述：<在什么时间范围内，哪个可查证的量出现什么变化，就说明假设错误>
- 查证方式：<数据源 / 文件 / 渠道，指明具体来源，而非"网上" >
- 到期日：<YYYY-MM-DD>
- 退出条件：<一旦该信号被观测到，应采取的具体动作>
```

示例：

```
信号 #1
- 陈述：若 12 个月内公开零售渠道的整机均价未下降，说明成本约束并未真正松动。
- 查证方式：主要电商平台同规格产品挂牌均价的月度抽样记录。
- 到期日：2027-04-30
- 退出条件：均价连续 3 个月未下降 → 视为成本约束未松动，停止扩大投入，只保留观察仓。
```

**数量要求**：不少于 5 条。其中至少 1 条应指向**约束层**，至少 1 条指向**需求层**（真实付费/复购），至少 1 条指向**信息层**（是否只是媒体放大）。

---

## 2. 证据到期日设定规则

到期日不是"什么时候会有结果"，而是**"最迟什么时候必须能观测到结果"**。设定规则：

1. **锚定指标的自然披露周期**：月度统计的指标，到期日设在月末数据发布后数日；季度性披露的指标，设在财报/季报窗口之后。
2. **不超过主假设时间窗口**：证伪信号的到期日必须落在阶段 0 设定的时间窗口内或其终点附近，否则无法用于当期决策。
3. **可观测优先**：若某指标无固定披露周期，则指定一个**可自行采样的时点**（如每季度人工抽样一次）。
4. **分层到期**：至少设置一个**中间检查点**（窗口中点）和一个**终点检查点**（窗口终点），避免只在最后才判断。
5. 到期日必须是**具体日期**（YYYY-MM-DD），不得写"以后""半年内看看"。

---

## 3. 退出条件写法示例

退出条件 = **触发判据 + 具体动作 + 幅度**。三者缺一不可。

- 触发判据：什么样的观测结果算触发（数值、方向、持续时长）。
- 具体动作：停止投入 / 收缩 / 转向 / 清仓 / 维持观察。
- 幅度：收缩到什么程度、保留多少。

示例：

- 「需求层：若连续两个季度复购率低于 X%，则把投入削减至原计划的 1/3，仅保留最小验证。」
- 「约束层：若监管放开仅停留在试点城市、未扩容，则按"可逆松动"处理，暂停任何不可逆的产能投入。」
- 「信息层：若某关键数据在三个月内被权威来源明确否认，则判定为叙事，全面停止投入并复盘。」
- 「机制层：若主力订单从"已签约"变为"仅意向"，则视软预期为动工风险，退出扩展性投入。」

---

## 4. 硬规则

1. **没有退出规则的趋势判断，不允许建议投入不可逆资源。**
2. 退出条件必须与证伪信号**一一对应**，不得出现"有信号无退出"的情况。
3. 触发即执行，不得以"再等等""再确认一次"为由拖延——拖延属于阶段 6 的"退出太晚"错误类型。
4. 所有退出动作都应**可逆或低损失**；若某一动作不可逆，必须在备忘录中显式标注并说明理由。
